1. Mission Overview

The mission focused on learning and performing basic Linux operations through the command-line interface. The activity involved navigating the Linux file system, identifying system and user information, creating directories and files, and viewing file contents. The mission helped me understand how Linux commands are used to manage files and interact with the operating system efficiently.

2. Objectives

The objectives I achieved were:

To understand the basic Linux command-line environment.
To identify the current working directory and active user.
To check the system hostname.
To view files and directories.
To navigate between directories.
To create new directories and files.
To display the contents of a file.
To become familiar with commonly used Linux commands.
3. Activities Performed

During the activity, I opened the Linux terminal and performed several basic tasks. I checked my current working directory and identified the active user and system hostname. I listed the available files and directories and practiced navigating through different folders.

I also created a new directory and added files inside it. After creating the files, I used commands to display and check their contents. These activities gave me hands-on experience in using the Linux terminal and understanding how commands are executed.

4. Linux Commands Used
pwd – Displays the current working directory.
whoami – Shows the currently logged-in user.
hostname – Displays the name of the computer or system.
ls – Lists files and directories.
cd – Changes the current directory.
mkdir – Creates a new directory.
touch – Creates a new empty file.
cat – Displays the contents of a file.
5. Skills Learned

Through this mission, I learned the following skills:

Basic navigation in the Linux file system.
Using the Linux terminal and command-line interface.
Managing files and directories.
Creating and organizing folders.
Creating and viewing text files.
Understanding the purpose and function of basic Linux commands.
Improving confidence in using a Linux operating system.
