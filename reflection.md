During this activity, I learned how to use Killercoda and GitHub as useful tools for practicing and documenting my Linux knowledge. Killercoda provided an interactive environment where I could execute Linux commands and explore the system without installing Linux directly on my computer. I practiced commands such as pwd, whoami, hostname, ls, cd, mkdir, touch, and cat. Through these activities, I gained a better understanding of navigating directories, creating files and folders, and viewing system information.
GitHub helped me organize and save the results of my activities. I learned how to create and edit files, write documentation using Markdown (.md), and commit my changes to a repository. This allowed me to keep a record of the commands I used and the skills I learned during the activity.
Overall, using Killercoda and GitHub improved both my technical and documentation skills. Killercoda gave me hands-on experience with Linux, while GitHub taught me the importance of organizing, saving, and managing my work. These tools helped me understand how practical exercises and version control can work together in learning technology and programming.
